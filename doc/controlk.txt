1. INTRODUCTION                                                *controlk-intro*

One picker for everything, selected by a prefix, in the style of Qt Creator's
Locator (Ctrl+K). Type nothing for open buffers, project files and line jumps.
Type a prefix and a space to switch to a source: symbols, CMake targets, help,
commands and more.

Prefixes must be followed by a space: `c Widget` searches classes for `Widget`,
while `c` on its own searches the project. The longest matching prefix wins, so
`cm` never triggers `c`.

==============================================================================
2. REQUIREMENTS                                            *controlk-requirements*

- Neovim 0.11 or newer is the stated requirement. Neovim 0.10.4, 0.11.7 and
  0.12.6 have been tested by hand.
- telescope.nvim. Tested with master, v0.2.2, v0.2.0 and v0.1.9.
- plenary.nvim.

Optional:
- ripgrep, for faster file listing. Git is the fallback.
- A language server for the symbol sources (`:`, `c`, `m`, `.`).
- cmake and ctest, for the CMake sources.

3. SETUP                                                          *controlk-setup*

With lazy.nvim, using the GitHub repository:
>lua
    {
      url = "git@github.com:hebercosfer/telescope-controlk.nvim.git",
      dependencies = { "nvim-telescope/telescope.nvim", "nvim-lua/plenary.nvim" },
      config = function()
        require("telescope").load_extension("controlk")
      end,
    },
<

The locator is mapped to `<leader>k` in normal mode when the extension loads,
with the leader set at that moment: set |mapleader| before your plugin manager
loads plugins. Choose another key with `keymap` (see |controlk-config|), or set
`keymap = false` to map nothing. A key you have mapped yourself is never taken
over.

Qt Creator's own key, Ctrl+K, is not the default because most configurations
use it to move between splits. If yours does not, `keymap = "<C-k>"` gives you
the Qt Creator key, or map it yourself:
>lua
    vim.keymap.set("n", "<C-k>", "<cmd>Telescope controlk<cr>", { desc = "Locator" })
<

4. SOURCES AND PREFIXES                                          *controlk-sources*

Enter does the action listed. "Needs" lists what a source requires.

  Prefix      Source                                     Enter does      Needs
  ----------  -----------------------------------------  --------------  -------------
  (none)      file system (as f), line jump (as l)       open, or enter
                                                         the directory
  o           open buffers                               open
  a           files in the project                       open            rg or git
  l           line, or line:column, in current buffer    jump
  f           file system, prefix match on names         open, or enter
                                                         the directory
  ?           the prefixes, with their sources           puts prefix in
                                                         the prompt
  h           Neovim help tags                           open help
  t           Ex commands                                fills :name
  b           marks                                      jump
  =           Lua expression                             copies result
  !           shell command                              runs in terminal
  r           web search engines                         opens the URL
  :           workspace symbols                          jump            LSP with
                                                                         workspace/symbol
  c           workspace classes, structs, enums          jump            LSP
  m           workspace functions, methods, constructors jump            LSP
  .           symbols in the current document            jump            LSP with
                                                                         textDocument/documentSymbol
  cm          CMake build targets                        builds in       cmake
                                                         terminal
  cmo         CMake target definitions                   jump            cmake
  ct          CTest tests                                runs in         cmake, ctest
                                                         terminal

Enter on an empty list, or on a hint row, opens the section below for the
source the prompt selects: `c Widgte` with no match opens
|controlk-source-lsp_classes|. The tags use source ids, not prefixes, so they
stay right when you rename a prefix.

------------------------------------------------------------------------------
Source reference

Default view                                            *controlk-default-view*
    With no prefix, the locator browses the file system as `f` does, and a
    number jumps to that line as `l` does. `default_sources` sets this: the
    default is `{ "filesystem", "lines" }`. To search open buffers and every
    project file instead, set
    `default_sources = { "buffers", "files", "lines" }`.

Prefix list (`?`)                                *controlk-source-prefixes*
    Lists every configured prefix at once, without a space. Enter replaces
    the prompt with the chosen prefix and a space, and the picker stays open
    on that source.

Prefix suggestions                                *controlk-prefix-suggestions*
    A partly typed prefix lists the prefixes it could become before the usual
    results: `c` lists `c`, `cm`, `cmo` and `ct`, then the entries of the
    project root that start with `c`. Enter on a suggestion works as in the
    `?` list.

Open buffers (`o`)                                  *controlk-source-buffers*
    Listed buffers, most recently used first. `[+]` marks a modified buffer.
    Enter switches to it at its last cursor line.

Files in project (`a`)                                *controlk-source-files*
    Every file under the project root (the git root of the current buffer),
    from `rg --files`, or `git ls-files` without rg. Fuzzy matched on the
    relative path. Hidden and git-ignored files are skipped.

Line in current document (`l`)                        *controlk-source-lines*
    `l 42` jumps to line 42, `l 42:7` to line 42, column 7.

File system (`f`)                                *controlk-source-filesystem*
    One directory at a time, starting at the project root. Typing narrows by
    the start of each name, ignoring case. A typed path is followed:
    `src/wid`, `~/notes/`, `/etc/`. Enter on a file opens it; Enter on a
    directory goes into it, putting `src/` in the prompt. Hidden entries are
    listed. It does not create files.

Help tags (`h`)                                        *controlk-source-help*
    Every help tag on 'runtimepath'. Enter opens the help.

Ex commands (`t`)                                  *controlk-source-commands*
    Every Ex command, with the definition of user commands. Enter puts
    `:name ` on the command line, ready for arguments.

Marks (`b`)                                           *controlk-source-marks*
    Global marks and the marks of the current buffer. Enter jumps to the mark.

Lua expression (`=`)                                   *controlk-source-eval*
    `= 2*21` evaluates the expression as Lua and shows the result, or the
    error. Enter copies the result to the unnamed register.

Shell command (`!`)                                   *controlk-source-shell*
    `! make test` runs the command with 'shell' in a terminal split at the
    bottom of the window, from the project root.

Web search (`r`)                                        *controlk-source-web*
    One row per engine in `web.engines`. Enter opens the URL with
    |vim.ui.open()|.

Workspace symbols (`:`)                         *controlk-source-lsp_symbols*
Workspace classes (`c`)                         *controlk-source-lsp_classes*
Workspace functions (`m`)                     *controlk-source-lsp_functions*
    Ask the language servers attached to the current buffer for
    `workspace/symbol`; `c` keeps classes, structs and enums, `m` functions,
    methods and constructors. They need at least `lsp.min_query` characters:
    servers cap an empty query (clangd returns 100 results, mostly from the
    standard library), so the picker asks you to type instead.

Symbols in the current document (`.`)          *controlk-source-lsp_document*
    `textDocument/documentSymbol` for the current buffer, fuzzy matched.

CMake targets (`cm`)                            *controlk-source-cmake_targets*
CMake target definitions (`cmo`)                   *controlk-source-cmake_open*
CTest tests (`ct`)                                *controlk-source-cmake_tests*
    See |controlk-cmake|. `cm` builds the target in a terminal, `cmo` jumps
    to the line that defines it, `ct` runs the test in a terminal.

Your own sources                                         *controlk-custom-sources*

The `sources` option adds sources of your own, keyed by an id. Each one shows
in the `?` list and in prefix suggestions like a built-in source.
>lua
    sources = {
      todo = {
        prefix = "td",           -- optional; `prefixes.todo` overrides it
        title = "TODO comments", -- optional; shown in the `?` list, default: the id
        tag = "todo",            -- optional; the tag column, default: the id
        items = function(query, ctx, done) ... end, -- required
      },
    }
<
The id must not be a built-in one. A user source can also go in
`default_sources` and in `disabled`. When it takes a built-in's prefix, the
built-in keeps it and a warning names both.

`items(query, ctx, done)` is called for every change of the prompt. `query` is
the text after the prefix and its space. Call `done(list)` once, now or later
(from a job, for example), with a list of items. `ctx` holds `root` (the
project root), `origin_buf` and `origin_win` (where the locator was opened),
`config` (the resolved configuration) and `cache` (a table that lives as long
as the picker). Callbacks of |vim.system()| run in a fast event: wrap
`done` in |vim.schedule()| before calling it from there.

An item is a plain table. Every field is optional except `text`:

  `text`         what the row shows
  `detail`       shown after the text
  `tag`          the tag column; default: the source's tag
  `path`         a file to open, and to preview
  `bufnr`        a buffer to switch to (wins over `path`)
  `lnum`, `col`  where to put the cursor; 1-based
  `run`          function(item) called instead of opening anything
  `passthrough`  true when the source already filtered the results; fuzzy
                 matching keeps every row, in the source's order
  `ordinal`      the text fuzzy matching uses; default: `text` and `detail`
  `hint`         true for a message row; Enter does nothing
  `prompt`       Enter puts this text in the prompt instead of acting
  `pinned`       true ranks the row before every unpinned row

Example, a live grep that splits the query on two spaces into a pattern and a
glob (`g foo  *.lua`):
>lua
    items = function(query, ctx, done)
      local pattern, glob = unpack(vim.split(query, "  ", { plain = true }))
      if pattern == "" then
        return done({})
      end
      local cmd = { "rg", "--vimgrep", "--smart-case", "-e", pattern }
      if glob and glob ~= "" then
        vim.list_extend(cmd, { "-g", glob })
      end
      vim.system(cmd, { cwd = ctx.root, text = true }, function(result)
        local list = {}
        for line in result.stdout:gmatch("[^\n]+") do
          local file, lnum, col, text = line:match("^(.-):(%d+):(%d+):(.*)$")
          if file then
            table.insert(list, {
              text = text, detail = file .. ":" .. lnum,
              path = vim.fs.joinpath(ctx.root, file),
              lnum = tonumber(lnum), col = tonumber(col), passthrough = true,
            })
          end
        end
        vim.schedule(function() done(list) end)
      end)
    end,
<

5. CMAKE                                                          *controlk-cmake*

The CMake sources use CMake's File API, so they work with Makefiles, Ninja and
other generators. The build directory is the first one under the project that
contains a `CMakeCache.txt`. If none exists, the picker offers a "Configure
project" item.

Set `cmake.build_dir` to choose the directory explicitly. It can be a relative
name such as "build", or an absolute path.

6. STYLES                                                        *controlk-styles*

`style` chooses how the locator looks. Every Telescope layout and theme is a
style, and `cutie` is controlk's own.

  Style            Fits     Notes
  ---------------  -------  ------------------------------------------------
  default          yes      Telescope's own default, from telescope.setup
  flex             yes      horizontal when wide, vertical when narrow
  horizontal       yes      preview on the right, none under 120 columns
  vertical         yes      preview above the list
  ivy, bottom_pane yes      a full-width pane at the bottom
  dropdown, center yes      a compact box in the middle
  cutie            yes      after Qt Creator's locator, see |controlk-cutie|
  cursor           no       the theme: a 23-column list at the cursor
  current_buffer   no       covers the window you work in

The two that do not fit work, with a warning. `layout_config` is passed to
Telescope as is for the Telescope styles. For one call:
`:Telescope controlk style=ivy`. Telescope's own `theme=` and
`layout_strategy=` still work, and win over `style`.

Cutie                                                             *controlk-cutie*

`style = "cutie"` looks like Qt Creator's locator: a small prompt in the
bottom-left corner, right above the status line, and nothing else until you
type. The first character opens the list above the prompt and the preview to
its right; clearing the prompt hides them again. The best match is the row
right above the prompt. The status line and the command line stay visible.

  cutie.width     Columns of the prompt and the list. Default 60. "auto"
                  matches a sidebar split on the left: the leftmost window
                  at column 0, narrower than half the screen, from any
                  plugin. A floating file tree is not a split; it gives 60.
  cutie.height    Rows of the list. Default 15. A short screen gets fewer.
  cutie.preview   false turns the preview off. It is also left out when it
                  would be narrower than 20 columns.

7. CONFIGURATION                                                *controlk-config*

Every option is optional. These are the defaults, set through `telescope.setup`:
>lua
    require("telescope").setup({
      extensions = {
        controlk = {
          -- Normal-mode key for the locator. false maps nothing.
          keymap = "<leader>k",
          -- "default", a Telescope layout or theme, or "cutie".
          style = "default",
          -- Passed to Telescope for the Telescope styles.
          layout_config = nil,
          -- The cutie style. width: columns, or "auto".
          cutie = { width = 60, height = 15, preview = true },
          -- Prefix per source. false removes the prefix.
          prefixes = {
            buffers = "o", files = "a", lines = "l", filesystem = "f", help = "h",
            prefixes = "?",
            commands = "t", marks = "b", eval = "=", shell = "!", web = "r",
            lsp_symbols = ":", lsp_classes = "c", lsp_functions = "m", lsp_document = ".",
            cmake_targets = "cm", cmake_open = "cmo", cmake_tests = "ct",
          },
          -- Your own sources; see |controlk-custom-sources|.
          sources = {},
          -- Sources merged when no prefix is typed; see |controlk-default-view|.
          default_sources = { "filesystem", "lines" },
          -- Sources removed entirely.
          disabled = {},
          lsp = { min_query = 1 },
          cmake = { build_dir = nil }, -- or "build", or an absolute path
          web = {
            engines = {
              Google = "https://www.google.com/search?q=%s",
              DuckDuckGo = "https://duckduckgo.com/?q=%s",
              Wikipedia = "https://en.wikipedia.org/w/index.php?search=%s",
              cppreference = "https://en.cppreference.com/mwiki/index.php?search=%s",
            },
          },
        },
      },
    })
<

Examples:
>lua
    extensions = {
      controlk = {
        prefixes = { lsp_classes = "C", eval = false }, -- C for classes, no Lua prefix
        default_sources = { "buffers", "files" },       -- fuzzy search, no browsing
        disabled = { "web" },
        web = { engines = { Google = false, Neovim = "https://neovim.io/search/?q=%s" } },
      },
    },
<

A prefix is removed with `false`. A web engine is removed the same way. Each
engine's value is a URL with `%s` where the query goes.

Configuration problems (duplicate or invalid prefixes, unknown source ids,
invalid user sources) are reported as warnings when the extension is set up.

8. COMMANDS AND LUA API                                        *controlk-commands*

`:Telescope controlk`
    Open the locator. Same as calling the Lua function below.

Lua:
>lua
    require("controlk").open(opts)   -- opts: telescope picker options
    require("controlk").setup(opts)  -- the same table as extensions.controlk
    require("controlk").config()     -- the resolved configuration
<
